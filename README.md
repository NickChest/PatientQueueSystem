# PatientQueueSystem
Made as a project for Practicum 2

## Features
- Simple, clean interface
- One-page AJAX queue management
- Separated department queues
- Information screen queue announcement board
- Printing of queue slip
- Flexible queue with draggable records
- Removal of patients (with valid reason)
- Marking of patients as completed
- Saving of time and date data for future data mining use
- Flushing of queue after midnight
